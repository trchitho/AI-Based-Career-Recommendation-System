VẤN ĐỀ 1: GEMINI ĐANG XỬ LÝ ĐỒNG THỜI GENERATION VÀ EVALUATION
________________________________________
1. Vấn đề hiện tại
Trong thiết kế hiện tại, hệ thống sử dụng một lần gọi Gemini để xử lý đồng thời:
•	Sinh câu hỏi (question generation)
•	Đánh giá câu trả lời (evaluation)
•	Sinh câu hỏi tiếp theo (follow-up)
Cách tiếp cận này dẫn đến các vấn đề sau:
________________________________________
(1) Xung đột nhiệm vụ (Task Conflict)
•	Question Generation:
o	yêu cầu tính sáng tạo (creative reasoning)
•	Evaluation:
o	yêu cầu tính ổn định, có cấu trúc (deterministic reasoning)
→ Hai loại reasoning khác nhau bị trộn trong cùng một prompt → giảm chất lượng output.
________________________________________
(2) Output không ổn định
•	Follow-up question phụ thuộc trực tiếp vào kết quả evaluation
•	Không có control layer riêng cho question
→ dẫn đến:
•	câu hỏi lệch skill
•	lặp lại
•	hoặc không tăng độ khó đúng cách
________________________________________
(3) Khó debug và kiểm soát
•	Không thể xác định lỗi nằm ở:
o	prompt generation
o	hay evaluation logic
•	Toàn bộ flow là một black-box call
________________________________________
2. Giải pháp thay đổi
Tách pipeline thành 3 thành phần độc lập:
________________________________________
(1) Question Chain
•	Nhiệm vụ: sinh câu hỏi phỏng vấn
•	Input:
o	career context (Neo4j)
o	level (Fresher/Junior/…)
o	history (tóm tắt)
•	Output:
o	câu hỏi
________________________________________
(2) Evaluation Chain
•	Nhiệm vụ: đánh giá câu trả lời
•	Input:
o	question
o	user_answer
o	expected_skill
•	Output:
o	score
o	feedback
o	missing_skills
________________________________________
(3) Interview Orchestrator
•	Điều phối:
o	gọi Question Chain
o	nhận answer
o	gọi Evaluation Chain
o	quyết định next question

3.2 Implement từng phần
________________________________________
(A) Question Chain
// packages/ai-core/interview/question.chain.ts

export async function generateQuestion(input) {
  const prompt = buildQuestionPrompt(input)

  const res = await geminiClient.generate(prompt)

  return res.text
}
________________________________________
(B) Evaluation Chain
// packages/ai-core/interview/evaluation.chain.ts

export async function evaluateAnswer(input) {
  const prompt = buildEvaluationPrompt(input)

  const res = await geminiClient.generate(prompt)

  return JSON.parse(res.text)
}
________________________________________
(C) Interview Pipeline (Orchestrator)
// packages/ai-core/interview/interview.pipeline.ts

export async function interviewStep(session, userAnswer) {
  const evaluation = await evaluateAnswer({
    question: session.currentQuestion,
    answer: userAnswer,
    context: session.context
  })

  const nextQuestion = await generateQuestion({
    context: session.context,
    missingSkills: evaluation.missing_skills
  })

  return {
    evaluation,
    nextQuestion
  }
}
________________________________________
3.3 interview-service (KHÔNG chứa AI logic)
// apps/interview-service

@Post("/chat")
async chat(req) {
  return interviewPipeline(session, req.answer)
}
