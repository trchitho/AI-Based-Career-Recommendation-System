**Cypher query:**
```cypher
UNWIND $skills AS want
MATCH (mn:Mentor)-[:HAS_SKILL]->(sk:Skill)
WHERE toLower(sk.name) CONTAINS want
   OR want CONTAINS toLower(sk.name)
WITH mn, collect(DISTINCT sk.name) AS matched_skills, count(DISTINCT sk) AS match_count
RETURN mn.user_id, mn.name, matched_skills, match_count
```


## 10. INTEGRATION FLOW ✅ ĐÃ LÀM HOÀN CHỈNH

**Pipeline:** Similarity → Filter → Rank → Top-K → Output

**Interaction:**
- Similarity Engine → Matching Algorithm: Provide scored mentors ✅
- Matching Algorithm → Filter: Apply constraints ✅
- Filter → Ranker: Sort mentors ✅
- Ranker → Output: Top-K mentors ✅

**Implementation flow:**
```python
@router.get("/mentee/find-mentors")
def find_mentors():
    # 1. PostgreSQL-based matching (similarity scoring)
    pg_results = svc.find_mentors_for_mentee(current_user.id)
    
    # 2. Neo4j-based matching (graph traversal)
    graph_results = find_mentors_by_skill_overlap(...)
    
    # 3. Score boosting (integration)
    for match in pg_results:
        graph_bonus = graph_score_map.get(match.user_id, 0)
        if graph_bonus > 0:
            match.compatibility_score += graph_bonus * 0.05
    
    # 4. Re-sort after boost (ranking)
    pg_results.sort(key=lambda x: x.compatibility_score, reverse=True)
    
    # 5. Return top results (top-K selection)
    return pg_results
```
