5️⃣ Sinh embeddings nghề (vi-SBERT, 384D)
(đã thêm file models/vi_sbert/tokenizer_name.txt)
'Sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2' `
| Set-Content -Encoding ASCII models\vi_sbert\tokenizer_name.txt

python -m src.nlp.encode_jobs `
  --catalog data/catalog/jobs_vi_tagged.csv `
  --model models/vi_sbert `
  --include_skills `
  --batch_size 32 `
  --emb_out data/embeddings/jobs_embeddings_visbert.npy `
  --idx_out data/embeddings/jobs_index_visbert.json
✅ Kết quả:
data/embeddings/jobs_embeddings_visbert.npy  (1016, 384)
data/embeddings/jobs_index_visbert.json
________________________________________
6️⃣ Nạp embeddings vào PostgreSQL (pgvector)
python -m src.retrieval.pgvector_load `
  --table retrieval_jobs_visbert `
  --idx_json data/embeddings/jobs_index_visbert.json `
  --emb_npy data/embeddings/jobs_embeddings_visbert.npy `
  --normalize `
  --truncate
Bảng retrieval_jobs_visbert có vector(384) + metadata nghề.
________________________________________
7️⃣ Kiểm thử truy vấn ngữ nghĩa (pgvector search)
python -m src.retrieval.search_pgvector `
  --table retrieval_jobs_visbert `
  --topk 10 `
  --query_text "phân tích dữ liệu, Python, trực quan hóa BI" `
  --model models/vi_sbert `
  --alpha 0.85 --beta 0.0 --gamma 0.15 --probes 32
✅ Trả về top-10 nghề phù hợp với mô tả người dùng.
________________________________________
8️⃣ Sinh vector người dùng
python -m src.data.make_user_vector --user_id 9
✅ Kết quả:
data/embeddings/user_vector.npy
________________________________________
9️⃣ Sinh đặc trưng item & user (từ PostgreSQL)
(chạy khi DB đã có bảng retrieval_jobs_visbert)
a) Đặc trưng nghề (item_feats.json)
python -m src.recsys.neumf.build_feats_from_db `
  --db postgresql://postgres:123456@localhost:5433/career_ai `
  --item_out data/processed/item_feats.json `
  --user_out data/processed/user_feats.json `
  --item_id_mode onet_code
b) Tạo tương tác user–item (NeuMF training)
python -m src.recsys.neumf.build_interactions_bootstrap `
  --db postgresql://postgres:123456@localhost:5433/career_ai `
  --topn 500 `
  --neg_per_pos 4 `
  --out data/processed/user_feats.json
✅ Kết quả:
data/processed/item_feats.json
data/processed/user_feats.json
