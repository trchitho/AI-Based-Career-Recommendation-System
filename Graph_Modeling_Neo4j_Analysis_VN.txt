- Trait similarity ✅

```python
def find_mentors_by_skill_overlap():
    cypher = """
    UNWIND $skills AS want
    MATCH (mn:Mentor)-[:HAS_SKILL]->(sk:Skill)
    WHERE toLower(sk.name) CONTAINS want
       OR want CONTAINS toLower(sk.name)
    WITH mn, collect(DISTINCT sk.name) AS matched_skills, count(DISTINCT sk) AS match_count
    """
```

**Score calculation:**
```python
toFloat(match_count) / toFloat($total_wanted) * 100 + career_boost * 10 AS score
```

## 8. QUERY DESIGN ✅ ĐÃ LÀM HOÀN CHỈNH

**Find mentors with shared skills:**
```cypher
MATCH (u:User {id: $user_id})-[:HAS_SKILL]->(s:Skill) 
MATCH (m:Mentor)-[:HAS_SKILL]->(s) 
RETURN m, count(s)
```

**Career alignment:**
```cypher
MATCH (u:User)-[:TARGETS]->(c:Career) 
MATCH (m:Mentor)-[:WORKS_IN]->(c) 
RETURN m
```

## 11. CONSTRAINTS/CHALLENGES ⚠️ MỘT PHẦN

**Issues:**
- Graph size lớn ⚠️ (Chưa optimize cho large scale)
- Skill mismatch ✅ (Có fuzzy matching)
- Incomplete mentor data ✅ (Có fallback mechanisms)

**Solutions implemented:**
- Normalization trước graph ✅
- Indexing ✅:
```python
"CREATE INDEX mentor_uid IF NOT EXISTS FOR (n:Mentor) ON (n.user_id)",
"CREATE INDEX skill_name IF NOT EXISTS FOR (n:Skill) ON (n.name)",
```
